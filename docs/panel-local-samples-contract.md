# V2 本地数值采样摘要

本地采样是显式可选能力。运行配置增加 `history_root` 后，V2 runtime 才会在该目录保存受限的数值采样；未配置时不创建目录，也不读写任何历史文件。相对路径以配置文件目录为基准。

每条记录只保留时间、配额窗口余量、上下文百分比、当前请求输入/缓存输入 Token、压缩次数和受限模型名。记录按七天与数量上限清理，写入使用临时文件替换并限制为用户可读。面板只接收样本数、覆盖时长、最低余量、上下文峰值、平均缓存占比和模型名摘要，不接收文件路径或原始会话内容。

2026-09-24 修正多任务目录模式：本地历史只从 `selectedThreadId` 与页面当前任务一致、且 `thread_id` 匹配的摘要读取上下文和模型；其他侧栏任务即使排在列表第一项也不能写入当前样本。身份不一致时保留空上下文，不混入其他任务的健康值。

2026-09-24 补充账户隔离：官方 [`account/rateLimits/read` 协议测试](https://github.com/openai/codex/blob/main/codex-rs/app-server/tests/suite/v2/rate_limits.rs) 的响应含字符串 `accountId`。V2 仅在该字段有效时向面板传递 SHA-256 摘要，不传原始 ID；数值样本和速度估算按此摘要分组，防止切换账户后把上一账户的下降曲线用于当前账户。没有账户 ID 时仍可保存无身份的基本数值摘要，但不生成跨时间的耗尽速度。该改动复用 Python 标准库 `hashlib` 与现有 `LocalSampleStore`，不增加依赖；合成双账户测试覆盖样本隔离和切换后的速度回退，真实账户切换仍待验收。

运行时会用窗口余量的相邻数值样本计算有限的耗尽秒数与均匀进度差；只有观察到实际下降速度才显示“按当前速度”预算，重置时间本身不会被当成耗尽估算。紧凑栏保留百分比，悬浮标题优先显示该时间预算。

该实现位于仓库内 `LocalSampleStore` 与 `panel_samples.js`，不导入旧版历史/renderer 实现；安装包发布审计也会拒绝把历史数据或带敏感命名的文件放进候选目录。

## 验证

- Python 单元测试覆盖禁用/启用、数值白名单、节流、过期清理和原子写入。
- Chromium CDP r10 已验证 `payload.history` 与正文摘要同时出现，并保留健康提示、消息投影和现有布局控件。
- 候选 consumer 通过 Node 语法检查和 `audit_release.py`，旧 renderer 标记扫描无命中。
