# Codex Quota Monitor v2.0.9 · macOS

六款伴宠现各有待机、开心、担忧、提醒、等待和抚摸六种独立画面。修复抚摸与拖动手势冲突，并为落地反弹、悬停、抚摸和提醒换帧补充浏览器回归。逐格检查了新增素材的手部数量；每格仅保留一只可见手或爪。

本版还补齐了素材来源、图集校验和浏览器显示验收记录。后续互动与升级方向见[伴宠互动审计](companion-interaction-audit-2026-09-25.md)。

已安装 v2.0.3 或更新版本的用户可在面板点击“检测更新”升级到本版。更早版本需手动下载 ZIP 与 `SHA256SUMS`，校验后按包内 `RELEASE.txt` 操作。旧目录和 Python 虚拟环境应保留以便回退。发行包未签名或公证。

发行包继续包含 Kevin Ke 与 Ailble 的 MIT `LICENSE` 和 `NOTICE`。测试范围见[验收记录](ACCEPTANCE-v2.0.9.md)。
