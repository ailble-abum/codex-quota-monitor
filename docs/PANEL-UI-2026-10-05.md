# 展开面板整理与底部位置修复

2026-10-05。根据用户截图调整 V2 展开面板，并修复靠下放置后展开、收起导致位置上移的问题。

## 界面调整

- 主面板优先显示账户额度和当前聊天上下文，账户明细、七天采样记录默认折叠。采样次数继续明确标为“次采样”，不表示 Token 消耗。
- 设置使用独立视图，显示选项直接可见，默认上下文、伴宠、提醒、版本与连接按组展开；提供返回用量入口。
- 顶栏使用统一的 28 × 28 CSS px 点击区域；刷新与设置使用 16 × 16 SVG 图标，收起按钮保持居中。显式限定按钮外边距、内边距和行高，抵抗宿主通用样式干扰。
- 保持浅色、深色、中英文、尺寸预设与紧凑栏；恢复复选框的原生外观。语言切换保留设置视图及分组展开状态，软件更新提示会打开对应分组。

复用本项目已有原生 `details`、事件委派、CSS 和布局模块。本轮属于既有 UI 整理与回归修复，不涉及新能力或依赖选型；没有引入第三方 UI 包，也未读取或复制旧版渲染实现。既有资源归因不变。

## 位置问题

浮动面板在屏幕底部展开时会临时上移，以完整显示内容。原来的 `keepTogglePosition` 在收起时取渲染后的 `rect.top`，把临时避让位置写回了两个模式的保存坐标。

现在切换模式保留已有的用户坐标，视口限制只影响显示位置。新增回归使用真实指针拖动到靠下位置，连续展开、进入设置、返回、刷新并收起；同时检查窗口缩小后恢复时的原位置。既有靠边伴宠测试继续验证左右两侧锚点不变。

在新 UI 中单独换回旧布局模块，回归明确失败：`bottom anchor drifted: 710 -> 78.390625`；使用修复后的模块，同一用例通过。
