# V2 近 7 天采样报告

2026-09-24。显式配置 `history_root` 后，V2 用已核对的当前任务摘要记录本地数值采样。面板新增近 7 个 UTC 自然日的采样次数、上下文峰值和模型采样次数。报告按账户摘要隔离，保留上限仍为 7 天；不读取消息正文，也不把采样次数解释为 token 消耗或请求次数。

项目排行依据已验证任务的 `session_meta.cwd`，只保留路径 SHA-256 摘要和最后一段目录名称，按该项目在本地采样中出现的次数排序。完整路径不写入历史文件，也不进入面板；工作目录之后若发生变化，记录反映的仍是该任务元数据中的工作目录。模型与项目排行都是**采样次数**，不是 token 消耗。测试覆盖身份冲突、跨账户隔离、日聚合、浏览器 DOM 文本安全和旧摘要兼容；这些仍是合成验证。字段依据 [OpenAI Codex 的 rollout 测试结构](https://github.com/openai/codex/blob/main/codex-rs/app-server/tests/common/rollout.rs) 核对。
