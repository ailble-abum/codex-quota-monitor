# 候选视图挂载替换

2026-09-20，接续 45d77a8。本轮在隔离候选中移除旧 ensureStyle / ensureHud 函数，加入 V2 自写的 DOM 创建、节点所有权检查与事件委托。现有头部 HTML/CSS 模板继续从固定外部来源提取并归因，没有将外观或图片重新设计。

## 范围与接口

构建输入、来源提交、六份输入摘要、原 LICENSE/NOTICE、输出脚本摘要与既有目录拒绝覆盖规则延续 [首次拆分](panel-split-contract.md)。本轮从已经固定摘要的两个函数内提取模板，再删除整个旧函数；不是在未知 JavaScript 中通用解析模板。模板若变化，先因输入摘要不匹配而拒绝生成，不能静默适配新版。

使用已存在的 DOM 原生 createElement/append、事件委托和闭包引用，不新增库或框架。面板文本、视图样式和布局/拖动辅助函数继续使用外部候选中的保留部分；其来源替换没有因此完成。

- ensureStyle 只创建本实例样式节点，不寻找或改写别人已有的同名样式。
- ensureHud 闭包保存自己创建的 panel；后续渲染复用同一对象，不重新绑定事件。已断开或同名查询指向其他节点时抛错，不接管替换节点。
- 头部事件在自己的 panel 上委托，覆盖单位、设置展开、标题展开、折叠和拖动后抑制点击。既有布局辅助函数负责位置与尺寸，仍需后续来源审计。
- 初始化保护仍拒绝已有根面板/样式/伴宠 ID；已有消费者 hook 的复用遵循前台入口原契约。本轮不支持热替换现用 renderer。
- 账户刷新按钮禁用：V2 暂无账户刷新后端，不能沿用旧 handler 的“约 10 秒内更新”承诺。按钮占位和布局保留，未来账户通路验收完成后再开放。
- 不增加消费者卸载或任意脚本回滚保证。初始化中途失败时既有消费者失败标记阻止重试，需要重新加载隔离页面；丢失节点后也不会猜测重建。只有数据桥退出清理已经具备验收。
