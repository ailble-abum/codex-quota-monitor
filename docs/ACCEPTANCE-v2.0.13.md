## 已完成的源码与合成验证

- 发布版本号更新后，Python 全套 270 项通过。更新测试分别覆盖本版号与下一版本，避免将本版误报为更新。
- Chromium / WebKit 的中英文、明暗主题、三种尺寸、键盘开关、状态颜色、长文本、设置导航、底部展开收起、左右停靠、默认上下文、卸载与节点所有权检查通过。源码验证记录见 `PANEL-UI-2026-10-05.md` 与 `CONTEXT-DEFAULTS-2026-10-04.md`。
- Apple Silicon 菜单使用当前 Swift 源码编译，部署目标 macOS 11；合成报告模式通过。
- Intel macOS 11 交叉链接缺少 Swift 兼容库。为避免破坏旧系统兼容性，发行包沿用 v2.0.12 已发布菜单的 x86_64 切片；Apple Silicon 使用新切片，两者合并为通用程序。Intel 菜单的既有功能不变，部分原生菜单文案尚未同步本版源码。
- 旧版输入 ZIP 从 GitHub 下载并核对 SHA-256 `7ead113ebd74dbd4745f23d666995e785bdb9588e3f11fa9c3529348309fa760`，其菜单程序摘要 `508d90c51bcf8885262626cccfce79ba9fa5432ed8068e1c6623c73869bb7a5d` 与原发行清单一致。双切片均标记最低 macOS 11；合成报告分别通过 arm64 原生执行与 Rosetta x86_64 执行。Rosetta 不等于 Intel 真机验收。
