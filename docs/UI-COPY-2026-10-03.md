## 语义与显示

- 额度显示剩余量，上下文显示已用量；ChatGPT 页面仍明确标为 Codex 额度，并提示没有提供 ChatGPT 上下文数据。
- 采样次数不改成 Token 消耗或完整账单；报告保留当前账户、UTC 日期和采样范围说明。覆盖首尾样本的时间改称“记录跨度”，避免暗示期间持续采到数据。
- 不直接显示 CLI / App Server / 错误代码等内部术语。错误代码保留在鼠标提示，未提供的界面探测不显示占位说明；有探测数据时显示“聊天识别”状态。

- 校正速度文字的方向：剩余额度高于均匀基线表示用量较慢，低于基线表示较快。显示单位改为百分点，保留原数值计算。
- 紧凑栏为完整中文标签补足 10 像素宽度；没有缩小字体或隐藏标签。构建候选保留原 LICENSE / NOTICE。
