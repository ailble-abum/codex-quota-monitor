# V2 独立重建设计

日期：2026-09-20。状态：整体重建方向已暂停；以 [最小替换范围审计](source-audit.md) 为准。后续已开始独立读取器实现，见 [读取器契约](reader-contract.md)。

## 目标与边界

用户希望产品更优秀，并最终移除对 KevinKE93/Codex-Monitor 派生实现的依赖。保留现有使用体验的核心价值：账户额度、上下文与 Token 观测、边缘伴宠、菜单栏和离线历史。

独立实现并不自动保证质量提高。V2 必须以正确性、资源消耗、断线恢复和可访问性证据证明改进。首版以 macOS 为交付平台；Windows 保留接口边界，实机验收独立推进。

不以清空 Git 历史、换语言、改名或相似度百分比判断是否消除派生关系。旧版本保留其 MIT 声明。新版本的许可和来源声明在来源审计结束后决定；不提前宣称完全原创或已取得法律结论。

## 模块设计

1. **只读事件读取器**：接收明确的会话根目录，仅增量读取追加字节。维护文件身份、偏移、未完成行；替换或截断时重新建立状态。损坏行有计数，末尾半行等待补全。
2. **会话状态归约器**：把来源已核实的模型、token、压缩事件归约为当前状态。区分本轮、累计、缓存与上下文；重复事件不重复计数，缺失数值标为未知，不能以零代替。未知事件忽略并可诊断。
3. **账户读取适配器**：通过官方本地接口读取额度，与会话 Token 独立。明确新鲜度、超时和账户切换边界；失败时不能把陈旧配额显示成当前读数。
4. **快照与历史**：所有展示消费同一带版本的快照。只持久化允许的数值摘要；默认不保留聊天正文、认证信息或完整路径。历史按来源和账户边界隔离。
5. **桌面连接层**：独立管理连接、目标窗口、重试和关闭。监视器不应在用户主动退出应用后强行重启应用。调试连接限制本机；连接失败不停止离线数据处理。
6. **展示层**：独立前端文件，展示配额、上下文、伴宠与详情；是否采用 Web Component/Shadow DOM 由最小交互探针决定，不能预设其一定兼容宿主。菜单栏读取相同快照。
7. **安装与诊断**：幂等安装、版本记录、明确失败原因、可回退。尽可能使用 Python 标准库；系统生命周期代码按平台隔离。

模块间只传递经过裁剪的结构化数据，不传整段会话。生产代码与测试夹具分开，夹具全部人工合成。

## 第一批实现范围

先完成只读事件读取器和会话状态归约器，提供离线命令行输出。输入格式先依据公开协议/官方源码核实并记录版本，不直接复制旧解析器或其测试。

验收覆盖：追加读取、UTF-8 跨读取边界、末行未结束、损坏 JSON、文件截断与替换、重复 token 事件、累计值回退、缺失上下文字段、模型切换、压缩事件以及多个会话隔离。输出不得包含正文和秘密。测试使用临时目录，不访问用户真实会话。

性能验收记录合成日志大小、耗时、峰值内存和追加读取字节数；已有文件未变化时不重新全量扫描。具体目标在基准数据生成后确定，避免凭空写性能承诺。

## 分阶段交付

| 阶段 | 交付 | 通过条件 |
| --- | --- | --- |
| 0 | 设计、固定基线、来源清单、官方接口调研 | 设计确认；每项来源标明文档/源码/实测证据 |
| 1 | 新事件读取器、状态归约器、离线 CLI | 合成输入正确性和增量性能验收通过 |
| 2 | 账户适配、快照、历史 | 超时、未知、陈旧、切换与恢复测试通过 |
| 3 | 桌面连接与独立 UI | 合成数据下深浅主题、键盘、拖动、吸附、缩放与重连实测 |
| 4 | macOS 安装与菜单栏 | 隔离安装、重启、卸载、升级失败恢复及原生 UI 验收 |
| 5 | 来源复核与发布准备 | 派生内容逐项处理；发行包内容审计；迁移与回滚验证 |
| 6 | Windows | Windows 真机安装、连接、UI、恢复与卸载验收 |

每阶段以聚焦提交交付，记录测试环境和未完成边界。阶段通过不代表全项目已完成。旧版切换和公开发布另按完成证据执行。

## 来源与独立实现过程

先建立不包含旧实现代码的行为规格，再据规格实现；记录规格依据、作者/Agent、实现提交和测试证据。已接触旧代码的参与者不能被包装成严格的洁净室实现。若需要更强的独立性证据，另行安排实现者访问隔离及来源复核。

允许采用成熟通用依赖，但保留各自许可。目标是替换特定上游派生实现，不是消除所有开源依赖或法定义务。旧版自有模块和素材也应先查来源再迁移。

## 成本与风险

此前 22–35/30–50 工程日和 6–10 周只是未基于完整任务分解的粗估，不作为承诺。阶段 1 完成后，以实际交付和未解决兼容性重新估算。

主要风险是宿主 DOM 变更、会话事件语义漂移、账户接口可用性、应用重启干扰和原生平台验收。来源审计也可能发现已拆分模块继承了上游内容，因此不能只替换五个同名文件就宣告结束。
