# Codex Quota Monitor v2.0.14 · macOS

修复默认上下文档位保存后总是回到“保持当前（默认）”的问题。保存、刷新或重新展开设置时，界面会按实际容量和压缩阈值显示对应的 256K、512K、1M 档位；自定义值和跟随模型显示为手动输入。

移除“保持当前”选项，在 256K 旁标注“默认”，并将系统下拉菜单换成与面板一致的平铺选择按钮。支持键盘箭头切换；选择后仍需点击保存，打开设置不会自动套用 256K，也不会自动重启 Codex。

在「设置 → 版本与连接」检查更新即可安装。保留旧目录和私有配置可用于回退。本版原生菜单二进制与 v2.0.13 相同，Intel 切片仍沿用已校验的旧版兼容程序；网页面板与 Python 运行链为本版代码。Intel 真机、Windows、签名与公证未验收。
