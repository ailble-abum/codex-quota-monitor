# Codex Quota Monitor v2.0.12 · macOS

这是 v2.0.11 之后单独发行的一版。v2.0.11 仍只包含上一版对 renderer 读取上限的修复，本页不改写那一版的说明。

本版修复新版 Codex 侧栏和伴宠面板：悬停提示改成两列，长内容可以滚动，并显示当前对话的压缩次数和压缩后首次请求占比。切回对话时保留已读进度；日志还没读完时显示加载，不再把旧值或半截结果当成当前上下文。标记为非活动的页面不再参与当前任务识别。

伴宠和面板共用同一条垂直中心线。右停靠从右上角缩放，展开和收回沿当前这一侧进行。长面板自动收回后，再次靠近先打开紧凑栏，紧凑栏按人物中心对齐。

已安装 v2.0.3 或更新版本时，可在面板点“检测更新”，确认后安装并重启。更早版本请下载本版 ZIP 与 `SHA256SUMS`，校验后按包内 `RELEASE.txt` 装到新目录。旧目录和私有配置留着，方便回退。发行包未签名或公证。

发行包继续包含 Kevin Ke 与 Ailble 的 MIT `LICENSE` 和 `NOTICE`。测试范围见[验收记录](ACCEPTANCE-v2.0.12.md)。
