# Codex Quota Monitor v2.0.1 · macOS

这是 v2.0.0 的正式补丁版。发布页、ZIP 和校验文件使用新版本号；旧 v2.0.0 包与标签保留。

## 更新内容

- 用新生成的“星瞳诺瓦”替换旧黑猫图像。提醒表情只保留一只抬起的前爪；保留 `cat` 皮肤键，已有偏好继续适用。
- 整理面板中继承的文案、宿主消息筛选和显示代码；保留发行包的 MIT `LICENSE` 与 `NOTICE`。
- “检测更新”默认查询本项目 GitHub 最新正式发行。点击后显示结果；在由 V2 LaunchAgent 管理的 macOS 安装中，可选择“安装并重启”。更新器下载指定正式版 ZIP 和 SHA256SUMS，核对包内文件摘要，在旧目录旁建立新版本目录，迁移私有配置并切换服务与菜单栏；切换失败时尝试恢复旧服务。旧目录保留，供回退和当前 Python 虚拟环境继续使用。

## 从 v2.0.0 升级

v2.0.0 尚无自动安装能力，需要从 [v2.0.1 发布页](https://github.com/ailble-abum/codex-quota-monitor/releases/tag/v2.0.1)下载 ZIP 与 `SHA256SUMS`，校验后按包内 `RELEASE.txt` 在新目录安装一次。此后正式版可以从面板检查并安装后续更新。不要同时运行两个监视器。

自动安装只适用于 macOS V2 自有 LaunchAgent；前台运行、其他安装方式和 Windows 不自动替换。若检查失败或服务不属于该安装，面板仍提供正式发布页链接。首次安装仍需 Python 3.9+、手动配置和终端；发行包未签名或公证。新版本沿用现有虚拟环境解释器，因此不要删除原安装目录，直到迁移其依赖环境。

## 验证与归因

Python 3.9 单元测试、Swift 类型检查、Chromium/WebKit 面板和贴边显示检查、发行包摘要审计通过。自动更新的下载、解包、配置迁移和服务切换回退使用合成测试；本次没有让测试改动现用安装或真实 LaunchAgent。五款其他伴宠和代码的来源边界见[资源记录](asset-provenance.md)与[源码复核](source-audit.md)，仍保留 Kevin Ke 与 Ailble 的 MIT 归因。
