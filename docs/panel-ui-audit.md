发现英文设置页的 “Reset to auto” 在标准 292px 面板内被压缩裁切。根因是伴宠大小行不允许换行，而设置按钮要求单行显示。复用现有 flex 布局，仅让该行在空间不足时换行，并保持重置按钮完整宽度；中文仍可保持单行。不增加依赖或新控件。

回归断言在旧样式上失败，修复后 Chromium/WebKit 均通过；另通过 208 项 Python 测试、样式检查和布局运行时检查。已目检修复后的 WebKit 英文暗色与中英文亮色截图，证据位于 `/tmp/quota-ui-fix-evidence`。截图和浏览器探针不等于真实 macOS Codex 窗口或 Windows 验收；现用安装未修改。

后续检查发现：允许长度内的连续模型名或项目名会让历史区横向溢出，面板根容器隐藏溢出后末尾不可见。旧版在 80 字符合成项目名上触发回归断言；仅给历史和会话说明文本区增加断词规则后，Chromium/WebKit 的 80 字符项目名与 128 字符模型名均保持在内容宽度内。已目检 `/tmp/quota-ui-longtext-evidence` 中的修复截图；不改变原始文本或数据边界。
