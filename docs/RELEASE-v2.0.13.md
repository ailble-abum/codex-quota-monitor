# Codex Quota Monitor v2.0.13 · macOS

用量面板重新整理了视觉和排版：突出额度数字，统一按钮与开关，减少重复边框和空状态。历史与账户明细按需展开，设置使用独立页面。面板放在屏幕下方时，展开后的临时避让不会再覆盖原位置，收起后能回到原处。

新增「设置 → 默认上下文」：默认保持当前设置，可选日常任务（256K）、长任务（512K）、超长任务（1M），也可手动输入。保存后可选择立即重启或稍后；容量受模型上限限制，这些档位不是模型能力承诺，也不适用于 ChatGPT 聊天。

同时包含新版 Codex 聊天身份适配、额度独立刷新、附加统计超时隔离与过期额度清理，并精简菜单、报告和提醒文案。采样次数继续与 Token 用量明确区分。

已安装 v2.0.3 或更新版本时，可在面板的「设置 → 版本与连接」检查更新并安装。更早版本请下载 ZIP 和 `SHA256SUMS`，校验后按包内 `RELEASE.txt` 安装。保留旧目录和私有配置以便回退。

发行包保留 macOS 11 的二进制兼容下限，包含 Apple Silicon 与 Intel 菜单程序。Apple Silicon 菜单使用本版源码重新编译；受当前工具链的旧版 Intel 兼容库限制，Intel 菜单沿用已校验的 v2.0.12 切片，部分原生菜单文案仍是旧版。两种架构的网页面板和 Python 功能均为本版代码。Intel 真机、Windows、签名与公证未验收。
