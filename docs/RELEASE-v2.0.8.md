# Codex Quota Monitor v2.0.8 · macOS

从本版起，后台检查发现新正式版时，面板会自动展开并显示更新提示。关闭后，同一版本不会反复自动弹出；发现更新的版本时会再提示。手动“检测更新”仍可使用，下载安装仍需用户点击“安装并重启”。

已安装 v2.0.3 或更新版本的用户可在面板点击“检测更新”升级到本版。更早版本需手动下载 ZIP 与 `SHA256SUMS`，校验后按包内 `RELEASE.txt` 操作。旧目录和 Python 虚拟环境应保留以便回退。发行包未签名或公证。

发行包继续包含 Kevin Ke 与 Ailble 的 MIT `LICENSE` 和 `NOTICE`。测试范围见[验收记录](ACCEPTANCE-v2.0.8.md)。
