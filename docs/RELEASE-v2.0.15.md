# v2.0.15

修复悬浮窗靠下展开后，调整大小、关闭靠边收起或拖动伴宠时位置上跳的问题。

- 面板的临时视口避让不再覆盖用户保存的位置；缩放和切换靠边设置后，收起仍回到原高度。
- 点击靠边面板不再立即解除停靠；只有实际拖动才移出边缘。中断拖动或丢失指针捕获会恢复原位置。
- 拖动伴宠只按伴宠自身高度限制范围，不再被展开菜单的高度拉向上方。
- 缩放手柄移入圆角内，减少把缩放误识别为移动的情况；兼容只有紧凑模式位置的旧记录。

位置专项 40 组验证覆盖 Chromium / WebKit、正常及减少动画模式；原有挂载、靠边、布局、设置和档位测试通过，Python 全量 270 项通过。详细证据见 [验收记录](ACCEPTANCE-v2.0.15.md)。

原生菜单源码未改，沿用 v2.0.14 已校验的通用程序。其中 arm64 切片来自 v2.0.13，Intel 切片沿用 v2.0.12；Intel 原生菜单部分文案仍为旧版，未声明 Intel 真机或 Windows 验收。保留 LICENSE、NOTICE 和资源归因。
