# v2.0.16

修复长期运行后顶栏一直显示未更新的问题，并精简菜单栏信息。本机 Work 对话的侧栏悬浮用量可以独立于当前打开的页面读取。

- 顶栏改为额度图标加剩余百分比；名称和状态放在鼠标提示中，窗口周期、重置时间等详细信息保留在菜单里。
- 修复历史记录超过 4 MB 后被旧菜单程序拒绝读取的问题；读取仍有 16 MiB 上限，过期或无效数据继续显示 `—`，不显示过期百分比。
- 在首页或非本地聊天页面，也可以悬停本机 Work 对话读取其用量。只显示经过身份核对的本机记录，不把悬停对象当作当前聊天，也不混入消息详情。
- arm64 和 Intel 菜单程序均由本版源码重新编译，不再沿用旧 Intel 切片；最低系统目标保持 macOS 11。

保留已有历史、设置、认证与聊天记录。验证及平台边界见 [验收记录](ACCEPTANCE-v2.0.16.md)。
