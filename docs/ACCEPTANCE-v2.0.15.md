# v2.0.15 验收记录

日期：2026-10-05。本轮针对悬浮窗位置异常，复用现有指针、布局和 Playwright 测试，没有引入依赖。

## 复现与修复

旧 v2.0.14 在独立临时页面中复现：靠下展开后更改靠边设置或缩放保存了临时上移的坐标；点击停靠标题即解除停靠；拖动伴宠受大菜单高度限制；取消拖动仍写入中途位置。另有仅保存紧凑布局的记录在首次收起时丢失原坐标，以及 Chromium 圆角裁切导致缩放手柄中心被识别为面板拖动。

修复保留用户位置与临时显示位置的区别，仅真实移动提交新锚点；缩放保留未移动的坐标，拖动取消恢复原布局，其他指针不能接管正在进行的操作。CSS 手柄移至圆角内部，伴宠拖动与大菜单独立限位。
